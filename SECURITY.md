# Security reporting

Please do not disclose credentials, customer data, unredacted FIX traffic or exploitable vulnerability details in a public issue.

For a private report, use GitHub's **Report a vulnerability** option on the repository's **Security** tab once it is enabled. Repository maintainers should enable and verify GitHub private vulnerability reporting under **Settings → Security → Code security and analysis**. Until it is verified, no private disclosure channel is confirmed; do not post sensitive details in a public issue.

FIX Multiplexer is intended for nonproduction use. See the [security review](docs/SECURITY_REVIEW.md) and [network setup](docs/CONFIGURATION.md#allow-developers-to-connect-over-a-network) for current limitations.
