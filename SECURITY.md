# Security reporting

Please do not disclose credentials, customer data, unredacted FIX traffic or exploitable vulnerability details in a public issue.

Before this repository is public, a private vulnerability reporting mechanism must be enabled and verified or a private maintainer contact must be approved. Until then, no verified private disclosure channel is available; do not assume a GitHub private-reporting button or an email address is active. Maintainers should update this file before publication.

FIX Multiplexer is intended for nonproduction use. See the [security review](docs/SECURITY_REVIEW.md) and [network setup](docs/CONFIGURATION.md#allow-developers-to-connect-over-a-network) for current limitations.
